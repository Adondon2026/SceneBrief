| --- | --- |

## 学术案例：波浪中船舶操纵性研究基准

| 版本 | 用户反馈与结论 |
| --- | --- |
| Research V1 | 像放 PPT，仅有船在移动；连续性单一、纵深不足。形成开工必须回顾的要求，任何证据都可接管主画面。 |
| Motion Lab V2 | 资料进入图形再进入空间场景的方向可行；但动作拖拉，信息丰富度和主体清晰度不足。 |
| Motion Lab V3 | 尝试短过渡、多主体及具体文献数据，强调先确定信息主体。仍需提高空间沉浸和连续性。 |
| Gemini 学术 V9 | 用户认可整体效果、情报终端视觉、信息丰富度；提出动效和一镜到底的连续性还需加强。此 V9 与港口 V9 不同。 |
| 学术 V10 Continuous Motion | 基于 Gemini 学术 V9，保留45秒、风格及信息结构；强化档案到场景、船型归档/调出、窗口身份及数据矩阵交接，修正重叠与叠影。 |
| 学术 V11 Tactical Depth | 用户提出并确认“主体突出展示，细节饱和堆积”，强调主体临场感，适合时使用 3D；新增主题相关、低权重、密集的辅助信息。用户表示对画面非常满意。程序化三维几何与 Canvas 投影，不是真实 CAD/CFD。 |
| 学术 V12 Cinematic Audio | 画面沿用 V11，仅优化45秒声音；用户认可，明确当前版本不再修改。声音仍为原创程序拟音，不是实录。 |

### 当前确认基线

学术 V11 的画面、V12 的音画组合为当前用户确认的视觉/声音参考。45 秒版本，不代表全项目固定时长，也不将黑红情报终端作为唯一视觉模板。

本轮依据对话和用户反馈整理规范；学术 V9–V12 是对话中交付的独立 HTML，V12 另有 WAV。记录文件名：research-motion-lab-v9.html、research-motion-lab-v10-continuous.html、research-motion-lab-v11.html、research-motion-lab-v12-audio.html、SceneBrief-V12-SFX.wav。此处仅记录版本与经验，并未上传这些成片，也未重新进行渲染或试听验收。历史分支已有港口 V9 与学术 Motion Lab V3 源码。不得将文件名当作已入库资产。

### 已确认的后续规则与探索

- 新作品底部保留字幕安全区，字幕可独立关闭与导出。对当前 V12 不做追溯修改。
- 视频导出加速属于独立技术探索：FFmpeg 硬件编码、减少 PNG 中间编解码、WebCodecs、WebGL/WebGPU；先测瓶颈，不因导出速度重构已经确认的画面。未进行本机加速性能验证，不承诺倍数。
- 后续将学术成熟版本归档并提炼可复用能力时，先保留原始可播放文件，明确资产授权、来源和验证范围；不可未经确认改动画面。


## Swift 科研案例：质量继承与增量开发

- Swift 第一版：78秒章节式展示，用户否定节奏、单调信息和断裂运镜。
- Motion Lab 02：18秒共享三维空间，从机体追踪、摄像头、FPV 进入感知与控制；用户认可。已入库，见 examples/swift-racing/motion-lab-02.html。
- Full V2：80秒重新实现而未继承样本，主体表现退化、固定面板重叠、指令遵循差；交付前实际浏览器渲染未通过。用户否定，后续对照复盘确认。仅记录失败经验，不作为基线。
- 2026-11-27 用户确认增量式动态制作：每批约20秒，直接继承已验收源码，累计版本，实际渲染、修正、视觉回归与交界连续性检查后才继续。具体执行见 WORKFLOW.md §7A 和 QUALITY.md。内部验收无需用户逐批确认；保留用户认可与内部验收区别。
