# 学术 V2：构图与镜头改造预案（未实施）

## 开工回顾

复用 V8 的对象连续、引导线生长、资料归档、快过渡慢阅读；继承 V9 的节拍与共同身份。修正 V1 六个固定面板的构图重复。借鉴 Modern Warfare 的空间化资料蒙太奇和 Apple 的来源对象连续缩放。下一轮先做 20–25 秒文献到物理机理的代表性片段，经视觉确认后推广。

## 分镜方向

| 节点 | 主角 / 景别 | 纵深与关联运动 | 核心信息 |
| --- | --- | --- | --- |
| 工程问题 | 海面远景 → 船尾桨舵特写 | 波面前景掠过；跟随船体走向，桨舵局部进入主画面 | 单桨单舵受限，环境改变任务可实现性 |
| 研究脉络 | SHOPERA 资料档案 → 单篇论文局部特写 | 资料在空间中前后错落；选中文献上浮并放大，原资料退后 | 已有研究解决了什么，待研究问题是什么 |
| 波浪耦合 | 论文图中船体轮廓 → 真实三维示意船体 | 对齐船体方向后图形转换；镜头进入船侧流场与载荷 | 波浪与操纵状态的耦合 |
| 模型辨识 | 物理量矢量 → 方程及参数 | 力矢量向对应项汇聚；公式主屏展开，保留局部水动力视图作为证据 | 物理量如何进入模型 |
| 能力边界 | 数学空间占据主屏 | 由运动轨迹扩展成概念能力域；不同环境条件逐层变化 | 任务是否可实现、余度及边界 |
| 精细控制 | 目标点 → 预测轨迹 → 反馈后的轨迹 | 同一目标在状态空间与船舶场景之间转换 | 如何利用边界指导闭环 |
| 验证 | 水池全景 → 船模/测量装置 → 对比数据 | 由模型映射至实验布置；图表局部展开 | 如何检验机理、模型、控制能力 |

实际论文图表、照片等在取得准确来源与使用许可后纳入；未取得时使用明确标注的示意图，不能伪造成真实研究证据。

## 验收

同一帧不应长期重复左船右卡的构图；至少有资料独立特写、图形转换与真实空间特写三类主角切换。逐段检查阅读时长、构图变化、转场关联、景别及前中后景。无实际浏览器观测时不得声称视觉达标。
